# 🧠 CrewAI Multi-Agent Blog Post Generator

Generate high-quality, research-backed blog posts using a multi-agent AI system powered by [CrewAI](https://github.com/joaomdmoura/crewAI). This project simulates a collaborative workflow between an internet research agent and a content writing agent — just enter a topic, and let the agents do the rest!

---

## 🚀 Features

- 🤖 **Multi-Agent Task Orchestration** with CrewAI
- 🔍 **Web Search** using Serper API (Google-like results)
- ✍️ **Content Writing** powered by OpenAI GPT-3.5
- 🖥️ **Simple Web Interface** using Streamlit
- ⚙️ **Error Handling** with LiteLLM (auto-retry on rate limits)
- 📄 **Markdown Output** with inline citations and references

---

## 🛠️ Tech Stack

- [CrewAI](https://github.com/joaomdmoura/crewAI) – Multi-agent orchestration
- [Serper API](https://serper.dev/) – Google search API for web data
- [OpenAI GPT-3.5](https://platform.openai.com/) – Content generation
- [Streamlit](https://streamlit.io/) – Web UI framework
- [LiteLLM](https://github.com/BerriAI/litellm) – LLM fallback & retry handling
